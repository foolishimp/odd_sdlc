# Common Tenant Design

This root holds shared realization/design law adopted across more than one
`odd_method` tenant.

Use `specification/standards/SPEC_METHOD.md` as the governing method reference
when writing or revising these files.

## Current Scope

The common design surface is currently structural and lightweight:

- standard tenant topology conventions
- shared rules for promoting tenant-local realization law to common surfaces

Promote content here only when more than one tenant truly adopts it.

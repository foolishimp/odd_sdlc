# odd_sdlc Code

This package is the first real `odd_sdlc` runtime slice.

It defines:

- the first ODD asset model over workspace bootstrap surfaces
- the first `odd_sdlc` function catalog
- the published GTL module for those functions
- the app-owned bootstrap and initialization surface
- the versioned `query-domain` plugin contract for UI/domain composition
- a CLI entry that runs through GTL and ABG

The code here is tenant-local.

It must not redefine GTL or ABG substrate law.

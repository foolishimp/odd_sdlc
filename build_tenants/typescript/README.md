# odd_sdlc TypeScript Tenant

This tenant is the planned ODD-native TypeScript realization of `odd_sdlc`.

It realizes the singleton `specification/` surface. It does not define a rival
product constitution.

Current status: scaffold only.

The scaffold intentionally exports only tenant identity. SDLC behavior enters
through later tickets after substrate binding, domain carriers, graph
publication, public start, hooks, projections, and qualification are landed.

## Commands

```bash
npm run build:semantic
npm run lint:semantic
npm run test:semantic
```

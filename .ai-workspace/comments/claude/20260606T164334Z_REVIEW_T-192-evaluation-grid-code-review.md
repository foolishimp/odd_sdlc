But only the **degenerate 1×k fused** case shipped. `evaluate/prompts.ts:200-201` hardwires `physicalExecution:"fused_prompt"` + `transformUnits:[transformUnit]`; the `bounded_cells` enum value has **no producer**; the fusion gate is a literal `obligationCount<=8` (`prompts.ts:212-219`), and **larger products fall back to the old broad prompt** — so the deep-product cost/block problem that *motivated* the reprice is unaddressed for exactly the products that motivated it.

## P1 — HIGH — §4/§7.13-14 side-door admission gap (the most serious finding)
The grid sidecar carries authority/evidence/lineage/closure payload — `authoritySnapshotRefs / priorFindingRefs / lineageRefs / abgOutcomeFoldRef` (`prompt_assets.ts:139-159`). Bootloader §7.13 requires payloads that affect *authority, evidence, ambiguity, traversal, or closure* to pass through ABG admission. Tracing every sink of the grid-bearing `invocationAsset`, all of them are **filesystem writes** (`installed_operator.ts:4375,4982` → `writeSdlcSystemArtifact`, a JSON-to-file serializer at `system_artifacts.ts:104-107`; `launch_contract.ts:9187` → `writeHandoffFile`). It **never reaches `emit()`** — the grid's authority/lineage/fold-ref payload is persisted as app-local archive bytes, never admitted through ABG. That's the prohibited app-local side-door pattern. **Adjudicate** whether the parallel `SdlcEvaluationGridContract` is a lawful read-model carrier or an unadmitted side-door. This is not resolved by any AssetSurface framing and is the headline item.

## P2 — MEDIUM — scalability is typed-but-unbuilt and UNTRACKED
The multi-segment producer doesn't exist (`bounded_cells` has no producer; `transformUnits` is always `[transformUnit]`); products over the `obligationCount<=8` gate get the old broad prompt. ## P3 — MEDIUM — per-segment redispatch unrealized + an UNFILED upstream abiogenesis dependency
Closure is **edge-monolithic**: every redispatch candidate is keyed to one `vectorIndex` = the edge index (`closure_state_machine.ts:555`); `postflight.ts:351-379` emits exactly **one** `GtlEvaluationFindingRef` (`findings=[finding]`); the released `GtlEvaluationFindingRef` has **no `segmentRef`/`dimensionRef`** (`compute_notation.ts:214-230`); and `targetVectorIndex` is validated into the **graph's edges**, never a segment-within-an-edge (`runtime_support.ts:86-99`, `graph_span_reentry.ts:398-399`). So a true n-segment grid with multiple segments inside one edge **cannot address a segment for redispatch** on the current substrate — a real upstream abiogenesis dependency. T-192's ABG Boundary (`:215-218`) and AC-8 (`req 18:675-677`) *pre-register* this contingency, but **no abiogenesis ticket was filed** (grep over `abiogenesis/.ai-workspace/tickets` finds none).

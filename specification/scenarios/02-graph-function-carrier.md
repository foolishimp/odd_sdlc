# Scenario Bundle - Graph-Function Carrier

**Validates**: REQ-F-GFUNC-001, REQ-F-GFUNC-002, REQ-F-GFUNC-003, REQ-F-GFUNC-004, REQ-F-GFUNC-005

**Purpose**: Prove that `odd_method` treats graph functions as the operative
constructive carrier and work vectors as productized views over that carrier.

## Scenario

Publish one named graph function, one composed graph function, one recursive
graph function, and one higher-order harness graph function for
outcome-driven work, then inspect the published surfaces.

## Significant Paths

- success path: a single graph function is published with explicit contract and
  intent
- composition path: a lawful graph-function composition is published without
  inventing a rival executor
- recursion path: a recursive graph function publishes termination and foldback
  truth
- higher-order path: a reusable consensus harness publishes its outer asset
  contract together with injected stage functions and policy without becoming a
  hidden engine primitive
- boundary path: a work vector is inspectable as a productized view over the
  backing graph-function carrier

## Expected Outcomes

1. published graph functions remain the operative constructive surface
2. composition and recursion are visible and lawful
3. higher-order harnesses remain inspectable graph-function carriers rather
   than hidden runtime engines
4. work-vector publication does not create a second runtime primitive

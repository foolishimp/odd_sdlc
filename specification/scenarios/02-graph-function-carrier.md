# Scenario Bundle - Graph-Function Carrier

**Validates**: REQ-F-GFUNC-001, REQ-F-GFUNC-002, REQ-F-GFUNC-003, REQ-F-GFUNC-004

**Purpose**: Prove that `odd_method` treats graph functions as the operative
constructive carrier and work vectors as productized views over that carrier.

## Scenario

Publish one named graph function, one composed graph function, and one recursive
graph function for outcome-driven work, then inspect the published surfaces.

## Significant Paths

- success path: a single graph function is published with explicit contract and
  intent
- composition path: a lawful graph-function composition is published without
  inventing a rival executor
- recursion path: a recursive graph function publishes termination and foldback
  truth
- boundary path: a work vector is inspectable as a productized view over the
  backing graph-function carrier

## Expected Outcomes

1. published graph functions remain the operative constructive surface
2. composition and recursion are visible and lawful
3. work-vector publication does not create a second runtime primitive

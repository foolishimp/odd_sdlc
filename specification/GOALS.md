# odd_method Goals

State the current overriding concerns for `odd_method` in present tense.

Use the installed method surfaces under `.genesis/docs/standards/` as the
governing standards while you fill this document out.

## Position

Goals focus one bounded wave of work.

They are narrower than product definition and shorter-lived than intent.

They keep the current repricing and bootstrap work oriented without turning
temporary focus into accidental constitutional law.

## Current Goals

- establish `odd_sdlc` as the first live ODD domain package
- define the ODD domain model around URI-addressed assets, typed asset nodes,
  named functions, bindings, gaps, and convergence targets
- keep URI fulfillment intentionally narrow in the first slice:
  `file://` and `http(s)://` now, `mcp://` later if it proves necessary
- make `AssetType` semantically meaningful by allowing type-driven `F_D`
  evaluation, `F_P` gap evaluation, and `F_P` descriptive framing
- publish the first `odd_sdlc` function catalog over typed asset graphs rather
  than collapsing back to one hidden project-global graph
- prove that typed asset-returning library graph functions can be injected into
  larger SDLC graphs as opaque contract-preserving producers, regardless of
  whether they are leaf, composed, recursive, or discovery-backed internally
- define the app-owned bootstrap and initialization surface that binds assets,
  resolves configuration, and runs graph-function work through ABG
- make the first executable slice a real app path:
  bind assets by URI, call a named function, materialize the graph, execute it,
  and audit the resulting runtime facts
- prove the first slice by post-mortem event audit and installed-dev behavior,
  not only by direct return values
- build a reusable consensus library carrier in `odd_sdlc` over GTL
  `fan_out`, `fan_in`, `gate`, and `recurse` rather than by introducing a
  hidden review engine
- standardize the first consensus asset surfaces as
  `review_assessment_surface`, `consensus_decision_surface`, and reviewed
  output surfaces so the same carrier can be injected over design, schema, DQ
  rules, release, and later domain-specific review problems
- keep consensus fully visible in ordinary ABG event and provenance flow so
  reviewer dispatch, review aggregation, gate outcomes, recursion rounds, and
  escalation remain inspectable as substrate truth rather than product-local
  summaries
- prove the consensus carrier first by sandbox lanes and then by a live lane
  before treating it as a stable reusable ODD library component
- keep GTL and ABG as stable substrate authority while `odd_method` proves the
  candidate GTL4 pressure in domain space
- keep non-ODD source material bounded to explicit translation provenance only
